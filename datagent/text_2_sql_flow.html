📋 流程要点

  • 入口：用户通过 POST /api/chat 传入自然语言问句 + shared_data 元数据
  • 路由：text_2_sql_agent 根据 (app, scene, type) 分发到不同场景代理，默认走 ge_c_query_analysis_agent
  • 数据集召回：调用远端 RPC 服务获取数据集 Schema（字段名、类型、枚举值）和业务知识
  • 分叉：根据数据集类型分 DSL 和 SQL 两条路；SQL 流程再按配置分单路径或多路径并行
  • 核心链路：LLM 生成 SQL → 远端执行 → 出错时工程纠偏/LLM 纠偏 → 重试 → 条件填充
  • 多路径选举：并行跑多个 LLM 路径各自生成 SQL→执行→纠偏，然后通过策略链（预过滤→逻辑筛选→LLM 投票→最终裁决）选出最优结果
  • 输出：表格数据 data（二维数组）+ meta_data（列信息）+ llm_info.llm_sql（生成的 SQL供核对）
